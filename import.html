Import samples

Add many samples at once from a spreadsheet. Start from the template, or use your own sheet if its headers are listed in the import guide.

  1. In Excel: File → Save As → CSV UTF-8 (Comma delimited). Plain "CSV" garbles accented letters.
  2. Choose the file below. Problems are listed and highlighted; nothing is saved.
  3. Run a dry run. The database checks every row and still saves nothing.
  4. Import. All rows are saved, or none are. At most 1000 rows per file.

Off: an STSSN that's already in the database is an error. On: that sample is overwritten with the file's non-blank cells. Blank cells never erase anything.

An STSSN contains the stranding date (ABC20240612-01). Filled dates are shown in green. A strand date that disagrees with its STSSN is always flagged.

Problems

    Automatic fixes

    STSSN repairs come from the lab's ID tool: two-digit years become four (ABC990612-01 → ABC19990612-01), underscores become dashes, stray spaces go. Start an ID with * to keep it exactly as written.
